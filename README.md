#  Веб-приложение для формирования расписания

Учебный проект — электронная доска для составления расписания учебных занятий.

##  Возможности

- Электронная доска расписания (группы × дни × пары)
- Поддержка 1-й и 2-й учебных недель
- Крупные информативные карточки занятий с цветовой маркировкой преподавателей
- Drag & Drop — перетаскивание занятий мышью
- Справочники: группы, преподаватели, дисциплины, кабинеты
- Связь «преподаватель → несколько дисциплин»
- Проверка конфликтов: преподаватель / группа / кабинет
- Авторизация пользователей и роли (админ / студент)
- Админ-панель для управления всеми справочниками
- Статистика нагрузки преподавателей

## 🛠 Технологии

- **Backend:** Python 3.11, Flask 3, Flask-SQLAlchemy
- **БД:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Авторизация:** Werkzeug Security
